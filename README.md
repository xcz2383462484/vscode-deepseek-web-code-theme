# DeepSeek (from Prism)

一个从 DeepSeek 网页代码高亮样式（基于 Prism）转换而来的 VS Code 深色主题。尽量模仿ds网页版高亮规则，有些许不同请见谅。
## 特性

- 编辑器背景 `#1b1b1c`，标题栏 `#151517`，界面跟随 Dark 2026 深色风格
- 覆盖 Python、C、C++ 常用语法（目前只支持这三个捏）
- 采用 TextMate + 语义高亮双层协作

## 安装

1. 下载 `deepseek-theme-x.x.x.vsix`
2. VS Code → 扩展 → `...` → Install from VSIX...
3. `Ctrl+K Ctrl+T` 选择 "DeepSeek (from Prism)"

## 配色参考

| 元素 | 颜色 |
|------|------|
| 关键字 / 运算符 | `#e9ae7e` |
| 字符串 | `#91d076` |
| 注释 | `#8da1b9` |
| 数字 | `#e6d37a` |
| 函数名 | `#c699e3` |
| 类名 / 内置类型 | `#6cb8e6` / `#f4adf4` |
| `#include` 的 `#` | `#6cb8e6` |
